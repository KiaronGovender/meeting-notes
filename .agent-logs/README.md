# Agent logs: provenance

**These are not output from the 8x capture tool.** I do not use a coding agent, so the capture tool had nothing to hook into. This folder is the closest honest substitute, and it is labelled as such.

## What was used

Everything AI-assisted in this project was done in a regular **AI chat assistant (Claude)** in a browser, not an agent running in my repository. In that chat I described what I needed, and the assistant wrote code and explanations. I copied the code into my own editor, ran it, tested it against real services, debugged it, and deployed it myself.

## What is in this folder

| File                                | What it is                                                                               | Who wrote it                                                 |
| ----------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `README.md`                         | This note                                                                                | Me                                                           |
| `chat-assistant/SESSION-SUMMARY.md` | A chronological summary of the chat session: what I asked, what was produced, what broke | Written by the chat assistant at my request, reviewed by me. |

## What is not here

- No logs were fabricated or reconstructed to look like capture-tool output.
- Secrets (API keys, database passwords) are removed from the transcript. Nothing else was altered.
